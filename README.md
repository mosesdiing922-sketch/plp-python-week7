# PLP Python Week 7 - File Handling Assignment

- `my_notes.py` - writes three notes, appends a fourth, reads them back and counts the lines.
- `my_notes.txt` - the notes file generated by `my_notes.py`.
- `report_builder.py` - reads `hubs.csv`, calculates the totals and writes a learner report.
- `hubs.csv` - the learner data (name, hub, score) used by the report builder.
- `report.txt` - the report generated by `report_builder.py`.

**What if `"a"` were changed to `"w"` in Question 1?** The second `with` block would overwrite the file instead of adding to it, so the first three notes would be erased. The file would contain only "I added this later" and the line count would be 1.
